# 逆転ドラマ 動画分析 — はじめての使い方

PythonとStreamlitで動く、YouTube Studioの動画別CSV分析ツールです。
YouTube API、APIキー、Google認証は不要です。実際のチャンネルデータは同梱していません。

## 入っているファイル

- `app.py`：ブラウザに表示する画面
- `analysis.py`：CSVの読み込み・列の判定・集計
- `requirements.txt`：必要なPythonライブラリ
- `.streamlit/config.toml`：画面の配色、ファイル容量などの設定
- `サンプル.csv`：架空の動画12本と合計行
- `test_analysis.py`：読み込み処理の動作確認
- `README.md`：この説明書

## Chromebookでのおすすめ：Streamlit Community Cloud

ブラウザだけで利用する場合、アプリを動かす場所が別途必要です。Community Cloudを使えば、ChromebookへのPythonのインストールは不要です。このファイルを作成しただけでは公開URLは発行されません。以下の設定を一度行ってください。サービスの画面名や無料枠・公開範囲の条件は変更されることがあります。

1. ZIPをダウンロードし、「ファイル」アプリで開いて中身を通常のフォルダーへコピーします。
2. GitHub（https://github.com/）にアカウントを作成・ログインします。
3. 新しいリポジトリを作成します。例：`youtube-drama-analysis`。これはプログラムを保存する箱です。
4. リポジトリの「Add file → Upload files」から、`app.py`、`analysis.py`、`requirements.txt`、`サンプル.csv`をアップロードし、「Commit changes」で保存します。ZIPそのものをアップロードするのではありません。
5. 利用統計の送信を無効にし、20MBの上限を適用するため、必ず「Add file → Create new file」でファイル名に `.streamlit/config.toml` と入力し、同梱ファイルの内容を貼り付けて保存します。隠しフォルダーが見えない場合も、この方法で作成できます。
6. Streamlit Community Cloud（https://share.streamlit.io/）にログインしてGitHubを接続します。
7. 「Create app」等の作成ボタンから先ほどのリポジトリ、実際のブランチ（通常 `main`）を選択します。メインファイルには `app.py` を指定します。Pythonのバージョンを選べる場合は **3.12** を選びます。
8. 「Deploy」で起動し、完了後のURLをChromebookのChromeで開きます。
9. 最初は「サンプルで試す」で動作を確認し、「自分のCSVを読み込む」に切り替えます。

Community Cloud・GitHubの管理画面、一部のStreamlit標準ボタンは英語表示になる場合があります。アプリの見出し、入力項目、グラフ、説明、エラー案内は日本語です。ファイル選択の「Browse files」は「ファイルを選択」、表の「Search」は「検索」を意味します。ブラウザの翻訳も利用できます。

**実際のCSVや制作メモはGitHubにアップロードしないでください。** アプリ画面で選択します。CSVは実行先のサーバーに送られ、そこで処理されます。アプリからの外部サービス送信・ディスクへの保存・他の利用者と共有するキャッシュはありません。チャンネルの非公開データを扱う場合は公開範囲やホスティングの条件を確認し、ご自身が管理する環境をご利用ください。公開アプリにした場合も、アプリのソースに実データを書き込まないでください。

## ChromebookのLinux機能で動かす方法（利用できる機種のみ）

学校・会社が管理するChromebookではLinux機能が制限される場合があります。その場合は上のクラウド方式を使います。

1. Chromebookの設定で「Linux開発環境」を有効にします。
2. 展開したフォルダーをLinuxと共有するか、「Linuxファイル」へコピーします。
3. Linuxのターミナルを開き、必要なものを入れます。

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip
```

4. アプリのフォルダーへ移動します。下記のパスは実際の保存先に合わせて変更してください。

```bash
cd ~/youtube-analysis
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

5. ChromebookのChromeで `http://localhost:8501` を開きます。ターミナルは開いたままにします。停止は `Ctrl + C` です。
6. 次回からはフォルダーに移動し、次の2行で起動できます。

```bash
source .venv/bin/activate
python -m streamlit run app.py
```

## CSVの用意と基本操作

1. YouTube Studio → アナリティクス → 詳細モードを開きます。
2. 集計期間を決め、動画（コンテンツ）別の表にします。クリック率、平均視聴時間、平均再生率、インプレッション数など必要な項目を追加します。
3. 書き出しからCSVを選択します。ZIPなら展開します。名称は環境で異なりますが、「表データ.csv」など、動画タイトルが行に並ぶ表を使います。「日付」「視聴回数」だけの時系列CSVではありません。
4. アプリ左側で「自分のCSVを読み込む」を選び、ファイルを選択します。
5. 自動判定が違う場合は「列の対応を確認」で、各項目に対応するCSV列を選びます。存在しない項目は「（なし）」のままで構いません。
6. 上のタイトル検索で絞り込み、3つのタブを確認します。
7. 「ドラマ制作メモ」に主人公・対立・逆転・結末などを記録し、「制作メモをCSVで保存」を押します。Chromebookの「ダウンロード」フォルダーを確認します。

- 最大20MB。UTF-8（BOM付き含む）、UTF-16、CP932の読み込みに対応します。区切りはカンマ、タブ、セミコロンを自動判定します。
- 再生数の `1,234`、率の `6.5%` に対応します。小数点は `.` を使ってください。小数点がカンマのCSVには対応していません。
- 率の値はYouTube Studioと同じ％単位を想定します。Excelで `0.065` に変えた値を `6.5%` に自動変換する機能はありません。
- 平均視聴時間は `0:08:30` など元の文字列を表示します。数値として平均・並べ替えを行う機能はありません。
- 主要指標を上の一覧で、CSVに含まれるその他の全指標を「CSVの全項目」で確認できます。英語CSVの元の見出しや動画タイトルは原文を保持します。
- 合計行は、タイトル列または動画ID列に「合計」「総計」「総合計」「Total」「Totals」がある場合に除外します。ほかの表記は元データで確認してください。
- 同じタイトルの動画も別の行として扱います。複数CSVの結合・重複動画の統合はしません。
- 絞り込みはグラフ・再生数合計・保存対象すべてに反映します。
- 集計期間のメモは表示・記録用です。入力しても期間の再集計はしません。
- 制作メモは自動保存されません。再読み込み・ファイル切り替え・絞り込み変更の前にダウンロードしてください。
- 保存した制作メモCSVを再度読み込むと、「CSVの全項目」でメモを参照できます。入力欄への復元と再編集もできます。
- CSV出力では表計算ソフトによる数式実行を防ぐため、`=` 等で始まる文字列の先頭に `'` が付く場合があります。

## この版の分析範囲

65歳以上の男性向けドラマの企画を記録するためのツールです。年齢・性別・国籍を推定したり、対象層の視聴だけに自動で絞ったりする機能はありません。

時間ごとの視聴維持率曲線、離脱時刻の判定、公開後7日などへの自動統一、YouTube APIとの連携はありません。平均再生率はCSVに含まれていれば表示できます。

比較は同じ集計条件・似た長さ・公開後日数・流入元を意識して行ってください。クリック率に一律の合格点は設けていません。動画全体の数値だけで特定の年齢層の反応や、再生数の原因は断定できません。

## 困ったとき

- **タイトル列がない**：日付別CSVではなく、動画別のCSVを選びます。
- **クリック率が出ない**：YouTube Studioの表に指標を追加して再出力するか、列の対応を選び直します。
- **文字化け**：Excel等でUTF-8のCSVとして保存し直します。
- **グラフが空**：タイトル検索を空にし、再生数の列を確認します。
- **クラウドで起動しない**：4つの必須ファイルが同じ階層にあるか、メインファイルが `app.py` かを確認します。
- **メモが消えた**：自動保存はありません。事前にダウンロードしたCSVを開いてください。

## 公開とデータ保護

- GitHubに公開するのはコード・設定・架空のサンプルだけです。CSVを選択する操作ではGitHubには送られませんが、クラウド利用時は実行先のサーバーに送られます。
- アプリには認証機能がありません。機密データには管理された実行環境を使用してください。ソースコードの公開と、実データを扱うアプリの公開は別の判断です。
- CSV・制作メモ・ダウンロード用データはセッション中のサーバーメモリに保持されます。アプリに外部API送信、アップロード内容のファイル保存、共有キャッシュはありません。ホスト側のログ、バックアップ、スワップやメモリ消去時期は保証しません。
- `.streamlit/config.toml` も配布してください。利用統計送信は無効に設定済みです。起動時の設定上書きにも注意してください。
- `.gitignore` でCSV（架空サンプルを除く）、秘密設定、出力先等を除外しています。ただしGitHubのブラウザでの直接アップロード、強制追加、すでに追跡されたファイルや過去のコミットには効きません。公開前にコミット内容と履歴を確認してください。
- サンプルは架空の動画名・数値と `sample_01` 等のダミーIDです。実データへ置き換えて公開しないでください。
- CSVダウンロードは全列を含む場合があります。元CSVや制作メモに個人情報があれば出力にも含まれるため、共有前に確認してください。
- 依存ライブラリはバージョン指定済みですが、将来の脆弱性を保証するものではありません。公開・運用時は依存関係の更新と脆弱性チェックを継続してください。
